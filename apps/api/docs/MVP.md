# myrota MVP v1

## Promise

**myrota helps you get more from the skincare you already own.**

Acquisition hook:

**Can I use these together?**

Behaviour hook:

**Turn your shelf into a 7-day rota — and actually stick to it.**

## Core object: My Rota

The product centres on a seven-day plan derived from products the user already owns.

Before the rota:
- what is on my shelf?

During the rota:
- what should I do today?

Around the rota:
- why was this scheduled this way?
- what is duplicated or missing?

Socially:
- do your own routine with me for seven days.

## V1 surfaces

### /
Landing proposition and build CTA.

### /build
Search provisional catalogue, select products, answer only context that changes output, reveal rota.

### /routine
Today + tappable week strip, AM/PM session completion, streak, one Rota Rescue, Shelf Check, invite.

### /mix
Two-actives relationship utility. Useful for search/social acquisition but subordinate to the main product.

### /invite/[code]
Friend landing page. Invitee creates their own rota.

## Gamification model

Borrow psychology, not Duolingo furniture.

Ship:
- daily Skin Streak
- one Rota Rescue per week
- Friend Streak
- milestone/share moments

Do not ship:
- XP
- leaderboards
- leagues
- gems
- arbitrary quests

A streak means **followed today's plan**, including planned recovery.

## Missed nights

The schedule does not chase missed sessions.

- skipped sessions are skipped
- never double up
- never compress intervals to "catch up"
- one missed day can be protected by Rota Rescue
- continue with the next scheduled day

## Friend loop

The shared object is accountability, not skincare advice.

```
Person A shelf → Person A rota
                       ↘
                    friend streak
                       ↗
Person B shelf → Person B rota
```

No routine cloning.

## Shelf Check

Maximum three observations.

Examples:
- no sunscreen detected
- multiple products doing a similar job
- strong treatment nights have been separated

No 0–100 score.

## Product ingestion target

V1 UI sequence:

1. search
2. ingredient photo
3. manual confirmation

Barcode stays later unless local benchmark shows it adds meaningful coverage.

## Early success metric

Do not use signup count as the north-star.

The strongest early viral metric is:

**invitee rota starts / invite opens**

Supporting:
- rota reveal → streak start
- D1 completion
- invite sends / activated user
- invite open rate
